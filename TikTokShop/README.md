## The one thing to know before doing anything else

You start at **zero followers**, and TikTok Shop Affiliate Creator status requires **1,000 followers minimum** (US, 18+, ID-verified) — see `01_build_playbook.md` → Eligibility. That means **day-1 content cannot be shoppable**. The real sequence is: post non-shoppable, trust-building content → cross 1,000 followers → apply for Affiliate Creator → then shoppable videos. The playbook is built around that reality, not around the fantasy of posting shoppable video #1 today.
